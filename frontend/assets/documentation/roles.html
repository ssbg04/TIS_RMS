Staff Roles & Access

Dedicated access controls for School Administrators and Classroom Teachers.

Roles & Permissions Overview
  • Administrator (Registrar): Full school-wide oversight across all grade levels and sections. Registers new learners, edits all student fields, modifies formal enrollment standing, manages school settings and document requirements, creates staff accounts, audits all system logs, and exports DepEd reports.
  • Teacher / Adviser: Focused access scoped to assigned advisory sections. Teachers can register new students, view assigned section rosters and virtual folders, edit permitted learner details (LRN, Name, Sex, Birth Date, 4Ps), upload scanned documents, and submit batch print requests.
  • Data Accountability & Security: The system enforces role-based access control (RBAC) across both client interfaces and the backend API, logging every modification with timestamps and user identifiers.

TIS-RMS separates responsibilities into two distinct user roles to ensure smooth daily operation while safeguarding the integrity of official learner records:
