Module 7: User Accounts

Staff account provisioning, role assignments, security controls, and password resets.

User Management Highlights (Administrator Access)
  • Staff Role Provisioning: Administrators can create accounts for Administrators and Teachers with automatic temporary credential generation.
  • Search & Status Filtering: Filter staff accounts by role (Admin vs. Teacher) and account status (Active vs. Deactivated).
  • Account Lifecycle Actions: Edit user details, toggle account activation, and trigger password reset links to registered email addresses.
  • Scoped Teacher Permissions: Teachers access only their assigned advisory sections and can edit permitted student details, while formal enrollment standing remains locked to Administrators.

Module 7 allows administrators to control access to TIS-RMS. Administrators configure who can log in, which advisory classes teachers can manage, and maintain robust credential security across all workstations.

Administrator Account Management Workflow

Administrators maintain full administrative control over all staff accounts:

  • Creating Accounts: Administrators can register new accounts for Administrators and Teachers, assigning them unique usernames, official school email addresses, and phone numbers.
  • Editing Information: Modify user details, phone numbers, or correct email addresses when staff information changes.
  • Status Controls: Instantly activate or deactivate accounts. Deactivating an account immediately blocks the user from logging in on any device.
  • Password Resets: Administrators can send secure password reset links directly to a staff member's registered email address.

Teacher Access Scopes & Account Security

  • Section Scope Enforcement: Teachers can access student records strictly associated with their assigned advisory sections. Advisory assignments are configured in Academic & Class Management.
  • Permitted Student Edits: Teachers can update allowed learner information (LRN, Name, Sex, Birth Date, and 4Ps) and register new learners for their advisory sections, but cannot alter formal enrollment standings or delete student profiles.
  • Self-Service Recovery: All users can update their own personal profiles and recover lost passwords via email One-Time PIN (OTP) verification.
  • Audit Trail: All account events (creation, profile updates, status changes, and password resets) are recorded in the system history.
