Talisay Integrated School - Records Management System

A dedicated, offline-first records and document management system built for Talisay Integrated School. Manage learner records with official 12-digit LRN tracking, scan SF9 and SF10 forms with automated OCR text recognition, track dynamic JHS & SHS compliance checklists, view DepEd statistical reports, and execute batch print requests — accessible on Windows desktop computers and Android mobile devices across the local school network or securely over the internet.

Windows Desktop Android App Works Offline & Online Real-Time Sync SF9 & SF10 OCR Scanning DepEd Compliance Reports Batch Print Queue Dynamic Checklists
System Highlights & Scope
  • Cross-Platform Parity: Full-featured Windows desktop suite paired with an Android tablet app tailored for classroom mobility.
  • Offline-First Resilience: Works 100% offline within the school local area network (LAN/Wi-Fi); zero dependence on cloud availability.
  • Secure Remote Internet Access: Configurable encrypted internet tunnels allow teachers and administrators to work remotely from home.
  • DepEd Standardization: Designed around Department of Education learner standards, Form 137 (SF10), Form 138 (SF9), and transparency boards.
