Module 3: Documents & Student Folders

Virtual learner document folders, camera scanning on Android, dynamic checklists, and built-in previews.

Documents Module Highlights
  • Folder & All Documents Views: Browse records organized into individual student folders or view all uploaded files in a searchable school-wide list.
  • Smart Context-Aware Uploads: Uploading from inside a folder automatically tags the student's LRN. Outside a folder, the system clearly notes that the document is unassociated.
  • Collapsible Requirement Checklist: View completed vs. pending documents right in the upload dialog to avoid missing files.
  • Mobile Scanner & File Preview: On Android, scan documents using the camera scanner. Preview PDFs and view images directly in the built-in viewer.
  • Print List Integration: Add documents directly to the batch print list with one click.

The Documents module replaces physical filing cabinets with structured digital envelopes. Document requirements are synchronized live from the backend — visit the Document Requirements Guide to learn how administrators configure requirements.

Admin & Teacher Side: Folder & Document Navigation

Both Administrators and Teachers can search and navigate documents and student folders:

  • Search: Quickly search documents and virtual folders by student name or LRN.
  • Folder Tab: Displays student digital folders with completion chips, and supports filtering by Grade Level and Section.
  • All Documents Tab: Displays all uploaded documents across the school or advisory classes, with filtering by document requirements retrieved from the backend.

Document Upload Workflow

Users can upload documents from files or via Android camera document scanner:

  • Context Detection: When uploading outside a student folder, the system shows a note indicating that the file is not currently associated with a student. When uploading from inside a folder, the system automatically detects and links the student's LRN.
  • Collapsible Requirements List: The upload dialog features an interactive collapsible list displaying mandatory and completed documents.
  • Platform Flexibility: On Android, staff can use the built-in document scanner with automatic border cropping and contrast enhancement. On both Windows and Android, files can be chosen directly from disk.

In-App Preview, Print Queue & Actions

  • Document Preview: Displays thumbnails and built-in previews for supported PDF and image files without requiring external software.
  • Add to Print List: Add selected documents directly to the batch print queue with a single click. For details on managing the print queue, visit the Batch Print Records module.
  • Document Actions & Multi-Select: Actions include preview, download, add to print list, archive, and delete. Multiple documents can be selected for batch operations.
